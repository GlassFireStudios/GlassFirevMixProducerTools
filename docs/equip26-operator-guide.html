Which block is it?

The show runs on 9 loop blocks. Each one belongs to a day and a time window. There are three ways to know which one should be on screen, and they always agree:

  1. The NOW button on the Stream Deck (yellow text) shows the date and block, for example THU OCT 22 | NOW 5 THU C. Press the block button with the same name.
  2. The card at the top of this guide works it out from Louisville time.
  3. By hand: the block name starts with its number and day. Find today's day, then the time window.

Going live uses the same block: on the vertical machine press LIVE plus the current block (Thursday at 2pm is LIVE 5 THU C). If the NOW button and the Windows clock disagree with your watch, post in Slack. The clock is what everything runs on.

Show day

Start of day (both machines)

  1. Power on. vMix opens with the Equip preset. If it doesn't, open vMix and use Open (top left) → C:\Equip\vMix\EQUIP26 Horizontal.vmix (or Vertical).
  2. Check the Windows clock in the corner matches Eastern time to the minute. The auto switch and countdown both run from it.
  3. Press the loop for the current block: the one the NOW button names (see Which block is it?). It goes red.
  4. Click Stream at the bottom of vMix. It turns red. Open the screen link on your phone and confirm the picture is there (about 3 seconds behind).
  5. Press AUTO SWITCH ON. Press COUNTDOWN ON. The countdown is invisible until an hour before the next event; that's normal.
  6. Post "Horizontal up" / "Vertical up" in #field-support.

During the day

  1. At each block time, glance at Output: the loop should change by itself within a few seconds. If it didn't, press the right block button.
  2. Keep the Stream button red. If it ever goes grey, click it again and tell Slack.

End of day

  1. Leave everything running unless GlassFire tells you otherwise. The screens show the loops overnight when the venue runs them.
  2. Post "End of day, all good" (or what went wrong) in Slack.

Going live

Live sessions (keynote, Morning Show, ENERGIZE, Tree Care Arena) go on both machines.

Horizontal

  1. A couple of minutes before: press the right BUG button for the session (Keynote, Morning, Energize, Tree Care, or Generic).
  2. Press AUTO SWITCH OFF so nothing changes under you.
  3. When the session starts: press LIVE CAMERA.
  4. When it ends: press the loop for the current block, then AUTO SWITCH ON.

Vertical

  1. Press AUTO SWITCH OFF.
  2. When the session starts: press LIVE for the current block (for example Thursday at 2pm is LIVE 5 THU C). The camera fills the top box and the graphics keep running underneath.
  3. When it ends: press the normal loop for the current block, then AUTO SWITCH ON.

The auto switch never cuts away from the camera on its own. It only changes things when a normal loop is on screen.

Practice

Run these on the machines before the show. Each one should take under a minute.

  1. Put 4 THU B on screen. Then 7 THU E. Watch the tally move from green to red.
  2. Go live on horizontal with the Keynote bug, then come back to the loop and turn auto switch back on.
  3. On vertical, go to LIVE 5 THU C and back to 5 THU C.
  4. Turn the countdown off and on. Reload it.
  5. Stop and start the stream, and watch the screen link go offline and come back.
  6. Close vMix and bring the show back from the preset, start to streaming, in under 2 minutes.

Get help

Double-click GlassFire Support on the desktop of either computer. Pick Something's wrong, Ask a question, or Send new media (for a new video or graphic from the client), and send. It tells GlassFire which machine you're on and what vMix is doing, and our reply shows up right there.

Slack #field-support works too, from your phone. Include which machine (horizontal or vertical) and a photo of the vMix screen if you can.

Show files update themselves: when GlassFire changes a time or a graphic, the computers pick it up within a couple of minutes. Don't copy or edit files in C:\Equip yourself.

If something is wrong on the screens right now, put the current block loop on first, then post.
